# Omah Kopi - Restoran & Kedai Kopi Nusantara

Landing page restoran kopi modern dengan stack sederhana: **HTML5, CSS3, Vanilla JavaScript (Frontend)** dan **Node.js + Express.js (Backend dengan penyimpanan file JSON)**.

## Fitur Utama
- **Desain Responsif & Modern:** Menggunakan CSS custom properties, flexbox/grid, dan pendekatan mobile-first.
- **RESTful API Backend:** Menyediakan endpoint dinamis untuk daftar menu, testimoni pelanggan, dan pencatatan reservasi meja.
- **Interaktif JavaScript:** 
  - Render menu dinamis dengan fitur filter kategori.
  - Testimoni carousel dengan *auto-slide* 5 detik.
  - Validasi form reservasi sisi klien (client-side validation) dan integrasi POST API.
  - Toggle navigasi burger untuk perangkat mobile.
  - Efek *scroll reveal* menggunakan Intersection Observer.
- **Aksesibilitas & SEO:** Dilengkapi meta tag Open Graph, dukungan *skip link*, struktur semantik HTML, serta *alt text* pada gambar.
